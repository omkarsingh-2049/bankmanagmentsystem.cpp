Bank Management System

A simple C++ console-based Bank Management System that demonstrates Object-Oriented Programming (OOP), file handling, encapsulation, and persistent data storage.

The application allows users to create bank accounts, deposit money, withdraw money, check account balances, and display all stored accounts.

Features

  • Create a new bank account
  • Automatically generate account numbers starting from 1000
  • Make deposits
  • Withdraw money with insufficient-balance validation
  • Check account balance
  • Display all bank accounts
  • Store account data permanently in accounts.txt
  • Load previously saved accounts when the application starts
  • Menu-driven console interface
  • Uses OOP concepts through Account and Bank classes
  • Uses encapsulation with private account data and public methods

Technologies Used

  • Language: C++
  • Concepts: Object-Oriented Programming, Encapsulation, File Handling, Vectors, Strings
  • Storage: Text file (accounts.txt)
  • Compiler: Any standard C++ compiler

Project Structure

BankManagementSystem/
│
├── BankManagementSystem.cpp
├── accounts.txt              # Created automatically to store account data
└── README.md

accounts.txt is generated by the program when account data is saved. It may not exist before the first account is created.

How It Works

The system is divided into two main classes:

Account Class

Represents an individual bank account and stores:

  • Account number
  • Account holder name
  • Account balance

It provides methods to:

  • Get account details
  • Deposit money
  • Withdraw money
  • Display account information
  • Convert account data to a text format for file storage
  • Reconstruct an account from stored text data

Bank Class

Manages all bank accounts using a vector<Account>.

It handles:

  • Loading accounts from accounts.txt
  • Saving accounts to accounts.txt
  • Searching for accounts by account number
  • Generating the next available account number
  • Creating accounts
  • Depositing money
  • Withdrawing money
  • Checking balances
  • Displaying all accounts

Menu Options

When you run the program, the following menu is available:

1. Create New Account
2. Deposit
3. Withdraw
4. Check Balance
5. Display All Accounts
6. Exit

Data Storage

Account information is stored in the following format:

AccountNumber,AccountHolderName,Balance

Example:

1000,John,5000.00
1001,David,2500.50

The program automatically loads existing accounts from accounts.txt when it starts and saves updated account information after account creation, deposits, and withdrawals.

How to Compile and Run

Using g++

Compile the program:

g++ BankManagementSystem.cpp -o BankManagementSystem

Run the program on Windows:

BankManagementSystem.exe

Run the program on Linux/macOS:

./BankManagementSystem

Using VS Code

  1. Install a C++ compiler such as MinGW (Windows) or G++ (Linux).
  2. Open the project folder in VS Code.
  3. Open the terminal.
  4. Compile the program using:
g++ BankManagementSystem.cpp -o BankManagementSystem
  1. Run the generated executable.

OOP Concepts Demonstrated

Encapsulation

The Account class keeps its data members private:

private:
    int accountNumber;
    string name;
    double balance;

Access is provided through public getter and operation methods.

Classes and Objects

The project uses two classes:

  • Account — represents a single account
  • Bank — manages multiple accounts

Constructors

The Account class uses constructors to initialize account information.

Abstraction

Bank operations such as deposit, withdrawal, and balance checking are implemented as class methods, hiding the internal data management from the main program.
